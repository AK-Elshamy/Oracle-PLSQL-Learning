# Database System Concepts

A hands-on learning repository for building strong database fundamentals
using *Database System Concepts*, MySQL, and MySQL Workbench.

## Learning approach

-   Learn concepts before memorizing syntax.
-   Practice every topic directly in MySQL Workbench.
-   Test constraints and edge cases, not only successful queries.
-   Write short notes in your own words.
-   Commit working examples to GitHub.

## Week 1 plan

1.  Day 1 --- Introduction to Database Systems; create a database and
    the first table.
2.  Day 2 --- Relational model, keys, and relationships.
3.  Day 3 --- SQL fundamentals: data types, constraints, `INSERT`, and
    `SELECT`.
4.  Day 4 --- Filtering, sorting, `UPDATE`, `DELETE`, and `NULL`.
5.  Day 5 --- Introduction to relational algebra.
6.  Day 6 --- Revision and a small practical project.
